# JenkinsTools.Client

Client for the public REST API of any Jenkins: `JenkinsSites` (configured sites, API tokens by reference), `JenkinsClient`
(one site: jobs, builds, console logs, test reports, queue, scan, start, wait, abort), `JobPath` (job and branch
addressing, Jenkins' double encoding of branch names). No dependencies beyond the BCL.

Source and documentation: <https://github.com/vbc-core-facilities/jenkinstools/tree/main/jenkinsclient>.
